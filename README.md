# Project Tracker API 🚀

A robust RESTful API designed to manage and track software projects. Built with Java 17 and Spring Boot, this project demonstrates enterprise-level backend engineering practices, transitioning from basic in-memory structures to a fully persistent, decoupled, and scalable architecture.

## 🛠️ Tech Stack
- **Language:** Java 
- **Framework:** Spring Boot (Spring Web, Spring Data JPA)
- **Database:** PostgreSQL
- **ORM:** Hibernate
- **Architecture:** MVC (Model-View-Controller)
- **Build Tool:** Maven

## 💡 Key Engineering Concepts Applied
- **RESTful Architecture:** Full CRUD operations with proper HTTP status codes and centralized exception handling (e.g., `ResourceNotFoundException`).
- **Data Persistence:** Integrated PostgreSQL via Spring Data JPA for robust data storage and retrieval.
- **DTO Pattern:** Implemented the Data Transfer Object (DTO) pattern using modern **Java Records** to decouple the API layer from the Database Entities, ensuring security and preventing mass-assignment vulnerabilities.
- **Dependency Injection (DI):** Strictly utilized Constructor Injection (Best Practice) across Controllers and Services.
- **Clean Code & Separation of Concerns:** Kept Controllers thin and focused purely on HTTP routing, offloading all business logic and mapping to the Service and Mapper layers.

## 📡 API Endpoints

| HTTP Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/projects` | Retrieves a list of all projects. |
| `GET` | `/api/v1/projects/{id}` | Retrieves a specific project by its ID. |
| `GET` | `/api/v1/projects/search?title={title}`| Searches for projects containing the specified title. |
| `POST` | `/api/v1/projects` | Creates and adds a new project to the database. |
| `PUT` | `/api/v1/projects/{id}` | Updates an existing project's details based on its ID. |
| `DELETE` | `/api/v1/projects/{id}` | Deletes a project from the database using its ID. |

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/zaidsardi/project-tracker-api.git](https://github.com/zaidsardi/project-tracker-api.git)
   Configure the Database:
Ensure you have PostgreSQL installed and running. Create a database named project_tracker (or update the database URL in the properties file). Update the src/main/resources/application.properties file with your PostgreSQL credentials:

Properties
spring.datasource.url=jdbc:postgresql://localhost:5432/project_tracker
spring.datasource.username=your_username
spring.datasource.password=your_password
spring.jpa.hibernate.ddl-auto=update
Run the Application:
Open the project in your IDE (e.g., IntelliJ IDEA) and run the ProjectTrackerApiApplication.java main class.

Access the API:
The API will be accessible at http://localhost:8080/api/v1/projects.
